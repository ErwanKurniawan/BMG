# Foto portofolio

Folder ini disiapkan untuk foto event, media, dan proyek digital final. Foto dummy saat ini berasal dari Unsplash.

Untuk memakai foto lokal, salin gambar ke folder ini lalu ubah properti `image` pada daftar `projects` di `src/pages/Home.jsx` menjadi path seperti `/images/portfolio/nama-proyek.jpg`.
